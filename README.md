FRONTED LOS TIEMPOS

Aplicación web frontend de TiemposPro, desarrollada con Next.js, React y TypeScript. El sistema permite visualizar transmisiones en vivo, consultar noticias y contenido multimedia, participar en conversaciones mediante un chat en tiempo real y administrar los contenidos de la plataforma.

Este repositorio contiene el desarrollo del frontend web, su integración con los servicios del backend y los archivos necesarios para su ejecución y despliegue mediante Docker.
